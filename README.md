# Application de bureau Resauvia

Installateurs de l'application de bureau de Resauvia (Auxentis), une version par dossier (`v1.0.2/`…) : Windows
(EXE, MSI), Mac (DMG), mises à jour signées et `version.json`. Chaque serveur Resauvia prend celle qui va avec sa
version, et vérifie l'empreinte de chaque fichier. Pour installer l'application, passez par la page « Télécharger » du
serveur de votre organisation.
